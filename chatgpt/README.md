# ChatGPT Prompts — Coming Soon

PromptSpace's public library currently focuses on **image generation** prompts
(Midjourney, FLUX, Stable Diffusion, DALL·E). Text-model prompts for
**ChatGPT** are curated on the live site and this open folder is reserved
for the community to contribute battle-tested ChatGPT prompts.

## How to contribute

1. Fork this repo.
2. Add a new `.md` file in this folder using the template below.
3. Open a PR — we review within 48h.

## Template

```markdown
# <Prompt Title>

**Model:** ChatGPT · **Use case:** <writing | code | analysis | agent | etc>

## Prompt

\`\`\`text
<the full prompt, copy-paste ready>
\`\`\`

## Example output

<optional 2–3 line sample>

## Notes

<optional: temperature, system-prompt tips, chaining hints>

---
Contributed by [@yourhandle](https://github.com/yourhandle).
```
